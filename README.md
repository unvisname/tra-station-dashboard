# 臺鐵車站潛力與商業供給儀表板

以臺鐵每日各站進出站開放資料（2024/1–2026/7）將全臺 235 個車站分為五種站型，
再結合車站 1 公里生活圈資料，找出「人流潛力高、周邊商業供給相對少」的車站，
並依站型與子型提出招商方向。

## 頁面

- 站型地圖（首頁）：235 站分布，可依站型、子型、日均人次、名單站篩選
- 潛力供給矩陣：各站型群內的潛力（人流）× 供給（餐飲家數／人流）位置與名單站
- 子型與招商建議：各站型子型的判定規則、人流特性與招商建議
- 車站體檢卡：單站逐日／星期／月別人流、1 公里生活圈指標、群內矩陣位置與招商建議

## 本機執行

```bash
pip install -r requirements.txt
streamlit run dashboard/站型地圖.py
```

## 資料來源

- 臺鐵每日各站點進出站人數（政府資料開放平臺 data.gov.tw/dataset/8792）
- 財政部全國營業（稅籍）登記資料
- SEGIS 社會經濟資料服務平台（最小統計區人口）
- 國土利用調查
- OpenStreetMap（餐飲點，對照用）
- 臺鐵旅運販賣空間出租資訊（115 年 2 月）
- Google Maps 餐廳家數（2026/11/7 查詢，僅使用 1 公里內家數彙總，輔助參考）

各資料時點不同，詳見各頁說明。
