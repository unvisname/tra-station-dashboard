# 臺鐵車站行為分群儀表板

以臺鐵每日各站進出站開放資料（2024/1–2026/7），將全臺 235 個車站依使用行為分為五種站型，
並結合車站生活圈開放資料（人口、POI、實價登錄），呈現站型地圖、案例站分析與站型業態建議。

## 頁面

- 站型地圖：235 站五群分布與各群特徵
- 案例站：對照站深入分析（運量節奏與生活圈指標）
- 站型與業態：各站型的商業配置建議

## 本機執行

```bash
pip install -r requirements.txt
streamlit run dashboard/站型地圖.py
```

## 資料來源

- 臺鐵每日各站點進出站人數（政府資料開放平臺）
- SEGIS 社會經濟資料服務平台（最小統計區人口）
- OpenStreetMap POI
- 內政部不動產成交案件實價登錄
